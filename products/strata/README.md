# DeepLab Strata

Product name chosen 2026-11-01. Replaces **DeepLab BKP**: the product now covers backup, disaster recovery, disk images (P2V/V2V/V2P), boot verification, Microsoft 365 backup, immutability and a built-in WAF, so "BKP" no longer fits. Remote management is marketed separately as **DeepLab Control** (product family, 2026-11-13).

## Naming
- Full name: **DeepLab Strata**. Short form after first mention: **Strata**.
- Never "Strata BKP", "DeepLab BKP" or "DLBKP" in anything a user sees.
- Tagline: *Every layer of your IT, protected.*
- Internal identifiers (`dlbkp-agent`, `dlbkp-server`, service names, binaries, install paths, Go module, repo name) **stay unchanged for now**. Installed agents auto-update, so renaming them needs its own migration plan.

## Logo
Part of the DeepLab product family ([../../BRAND.md#product-family](../../BRAND.md#product-family)). Generated by `family/build.py`; this README is hand-written, the image files are not.

Since 2026-11-13 the Strata mark is its own symbol (layers converging on one cyan restore point) instead of a copy of the DeepLab master mark, so a Strata tab or app icon can be told apart from DeepLab. File names are unchanged.
