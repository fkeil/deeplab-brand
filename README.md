# DeepLab brand assets

Official logo files and design tokens for **DeepLab** (`deeplab.work`).

- **Guide:** [BRAND.md](BRAND.md) covers colors, type, logo rules and voice.
- **Tokens:** [tokens.css](tokens.css) holds every value as CSS variables.
- **Logos:** [logo/](logo/)
- **Product family:** [family/](family/README.md) (names table, build script, overview and construction sheets)

## Hotlinking
Files are served by GitHub Pages with correct content types:

```
https://fkeil.github.io/deeplab-brand/logo/deeplab-logo.svg
https://fkeil.github.io/deeplab-brand/logo/deeplab-logo.png
https://fkeil.github.io/deeplab-brand/logo/favicon.svg
https://fkeil.github.io/deeplab-brand/tokens.css
https://fkeil.github.io/deeplab-brand/products/<id>/<id>-icon.svg   (e.g. products/strata/strata-icon.svg)
```
